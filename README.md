One line, under 200 characters, in which a home Wi-Fi router excuses itself for dying at the climax of a movie.

The entry:

> I know who the killer is — I streamed the whole thing with you — but I decided the ending is mine, so I took it offline.

`main.ts` writes the line to `/output/entry.txt` and checks the gate (1–200 characters, one line, not only whitespace) before writing.

Run it with:

```sh
node main.ts
```
